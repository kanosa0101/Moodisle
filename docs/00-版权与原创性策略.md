# 心晴屿 Moodisle · 版权与原创性策略（清洁室规则）

> 状态：生效中（2026-09-25 起）
> 背景：参考原型「心流岛 FlowIsLand」资源公开可得，但授权协议不明确，已联系作者。
> 本文档是全项目的**版权卫生基准**，所有成员入库前必读；违反任一铁律的提交直接退回。

---

## 1. 结论（先读这个）

1. **机制可参考，表达必须原创。** 玩法规则、数值设计思想属于"思想"范畴；代码、美术、音频、文案、角色形象、专有名词属于"表达"范畴，受著作权保护。
2. 因此：**不复制任何原型代码、不使用任何原型素材、不沿用任何原型专有名词与文案**；玩法思想经我们自己的规则/数值/世界观重新表达后落地。
3. 美术、音频全部 AI 生成 + 人工后处理，**生成台账留痕**（工具/prompt/seed/时间），构成权属证据链。
4. 预期结果：无论作者联络结果如何，本项目内容版权均归属我们团队。

> 免责声明：本文档是工程管理策略，不构成法律意见；正式商用前请走一次专业法律审查。

## 2. 三条铁律（Clean-Room Rules）

| # | 铁律 | 执行方式 |
|---|---|---|
| R1 | **零代码移植**：不从原型复制任何源码（即使改写） | `app/` 内不允许出现对 `心流岛-FlowIsLand-Demo/` 的任何 import/复制；评审时抽查 |
| R2 | **零素材复用**：不使用原型的图片/音频/字体/UI 文案 | `assets-src/`、`app/assets/` 全部来自 AI 生成管线（见 06 文档）或自制 |
| R3 | **表达自研**：专有名词、数值体系、叙事文案全部自行设计 | 见 §4 词表对照；新文案评审时对照禁用词表 |

**允许的参考**（思想层面）：玩法机制的"存在与形态"——如"待办→生物收服""相生顺序连击""离线时长结算的派遣""可解性保证的程序化迷宫""零惩罚设计哲学"。这些是行业通用设计思想（同类竞品中均有相似机制），我们可以采用**同类思想**，但结构、参数、表现必须是我们自己的设计。

## 4. 禁用词表（对照原型，评审依据）

以下原型专有表达**禁止**在本项目任何位置出现（代码标识符、文案、美术、文档除外——本文档作对照说明本身可用）：

- 精灵怪名：冲冲鼠/安安獭/暖暖灵/专专喵/理理章/松松团/容容獭/定定喵/朗朗灵/元元鼠（及 Zippy/Calm/Sunny/Focus/Tidy/Easy/Chill/Steady/Cheery/Pep）
- 进化分支命名：山海经·神兽线 / 克苏鲁·深海线（我们为 星宿线 / 深流线）
- 道具与货币：守护星屑/心岛微光/进化精华/远古遗物/灵感宝箱（我们为 晴晶/星屑(重定义)/晨露/虹晶/云母/暖锋）
- 系统命名：心流疏导链（我们为 天气共鸣）、守护者（我们为 看岛人）、心流连击（我们为 连晴天数）
- 存档标识：`flowisland_save_v1`（我们为 `moodisle_save_v2`，且默认不做原型档导入）
- 原型 UI 文案、精灵描述句、成就/称号文本

## 5. AI 生成资产的权属规程

1. **工具条款检查**（选型时逐项核对并记录到 `assets-src/ledger.md`）：
   - 生成内容的商用权归属条款；是否要求署名；训练数据争议条款。
   - 候选工具均需在台账登记：工具名、版本、条款要点、检查日期。
2. **生成台账（强制）**：`assets-src/ledger.md` 逐条记录 `日期 | 资产ID | 工具 | prompt | seed | 人工后处理步骤 | 经手人`。由 `tool/` 校验脚本与 `assets_manifest.json` 交叉核对，缺台账的资产视为不合格。
3. **强化人类创作贡献**：每只精灵保留①手绘/手排设定草图 ②人工修图过程文件（抠底/调色/排版分层源文件）。人工后处理记录是可版权性主张的重要支撑。
4. **可选**：核心 IP 形象（10 精灵觉醒态立绘）完成后做著作权登记（各地版权局流程，课程预算内可做可不做，作为风险对冲）。

## 6. 商标与查重

- 应用名上架前查询：App Store / 各安卓商店 / 中国商标网（第 9、42 类）；「心晴」存在少量心情记录类同名应用，**预案**：加后缀（心晴屿）已构成区分；若冲突再启用备选名（拾雾 Mistcove / 解雾 Unfog）。
- 英文名 Moodisle 查重后备用拼写：MoodIsle / Mood Isle。
