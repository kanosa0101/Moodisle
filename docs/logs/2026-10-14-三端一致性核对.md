# 2026-10-14 三端一致性核对

## 范围

本次核对目标是确认 Web、Android 与 iOS 的当前实现来自同一套 Flutter 源码，并对齐用户可见的名称、版本、图标、字体、音频和方向策略。编译通过不替代 Android/iPhone 真机交互验收。

## 结论

- 三端共用 `app/lib`、278 张运行时 PNG、13 项音频与 2 个 `MoodisleSans` 字体；运行时代码只有存档后端按平台分支：Web 使用 localStorage，Android/iOS 使用应用文档目录。
- 版本源统一为 `0.1.0+1`。Android 映射为 versionName `0.1.0` / versionCode `1`，iOS 映射为 `CFBundleShortVersionString=0.1.0` / `CFBundleVersion=1`，Web 构建元数据为 version `0.1.0` / build number `1`。
- 三端显示名为“心晴屿 Moodisle”；iOS marketing icon 与 1024px 主图逐字节相同，Android xxxhdpi 与 Web 192px 图标逐字节相同，其余声明尺寸均通过检查。
- Web PWA 原先单独声明 `portrait-primary`，Android/iOS 均允许旋转。页面本身使用 460px 内容栏和响应式约束，本次移除 Web 独有方向限制。
- Linux CI 与 iOS 手动工作流都固定 Flutter 3.47.5。新增 `tool/check_platform_consistency.py`，在普通 CI 中阻止上述元数据与资源再次漂移。
