## 2. 当前实现分层

```
app/lib/main.dart
  MaterialApp / AppShell：五项底部导航、成长入口、首次引导
  presentation/pages：心屿、待办、图鉴、回廊、专注、成长
  application/GameController：状态通知、计时心跳、业务编排、保存调度
  domain/GameCore + engine/entities：游戏状态与领域规则
  data/SaveCodec + SaveStore：JSON v2、原生文件存储与 Web localStorage
  shared/theme：Moodisle 主题 token 和共用组件
  shared/audio：应用级 BGM/音效服务与页面事件接线
```

- 页面使用 Flutter Material 组件和自绘画布；GameController 以 ChangeNotifier 通知 UI。
- GameCore 与领域实体承载任务、收服、气候、专注、生态和回廊逻辑。
- 当前架构没有 Riverpod、SQLite/Drift 层或独立 platform/桥接目录。
- 第三方运行时依赖为 path_provider 与 just_audio；后者的共享播放器和页面事件已接线。10 个本地合成 SFX 与 3 首用户提供 BGM 已加入运行时资源；两端实听验收待做。

## 3. 存档和生命周期

- 存档格式为 JSON v2。原生平台写入应用文档目录；Web 通过 localStorage 保存主档与有效备份。
- GameController 在首次状态变动后约 2 秒合并保存；专注计时使用 1 秒心跳。
- 专注流程接收 Flutter 应用生命周期变化；不同浏览器对标签页隐藏的生命周期语义仍需单独验收。
- JSON 导入/导出是迁移存档的入口。云同步不是当前能力。

## 5. 开发与验证

在 app/ 目录执行：

    flutter pub get
    flutter run -d chrome
    flutter analyze
    flutter test
    flutter build web --release --pwa-strategy=none
    flutter build apk --release

测试源码当前有 17 个文件、106 条测试。2026-09-28 全量回归记录为 106/106 通过；音频接入后的 2026-09-30 全量重跑同为 106/106（重跑时修复了三类测试环境问题：just_audio 平台通道在测试进程无实现，现由 `app/test/flutter_test_config.dart` 注入平台替身；一处日期敏感夹具改为相对当前时间；Windows 下 teardown 删临时目录偶发句柄锁改为重试删除）。当前没有 golden、integration_test 或 GitHub Actions 作为已执行验收证据。

字体说明：应用通过 `app/pubspec.yaml` 随包分发中文子集字体（`MoodisleSans` 族，`tool/subset_font.py` 从工程实际用字生成，SIL OFL 1.0 授权）。界面主体文本不再依赖 fonts.gstatic.com 的运行时下载；CanvasKit 对少量绕过应用主题的框架内部文本仍会按需请求回退切片（首访约 9 个小切片，浏览器有缓存后不再重复下载），完全离线的首次访问这部分可能短暂显示回退字形。

清洁室扫描脚本可从仓库根目录手动执行：

    python tool/ip_scan.py .

该脚本目前没有接入 CI 自动工作流。
