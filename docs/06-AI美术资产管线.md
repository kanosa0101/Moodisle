## 1. 风格方向

**采用：柔和贴纸插画（sticker illustration）**——扁平色块 + 暖棕粗描边 + 柔和噪点。理由：AI 批量一致性最好、多端多分辨率缩放稳定、与竞品（像素/厚涂）视觉区隔明显、小尺寸（组件/灵动岛）可读性好。

**风格圣经（公共提示词基座）**：

```
BASE = "soft flat sticker illustration, thick rounded warm-brown (#5a3e22) outline,
        pastel palette, subtle grain texture, kawaii proportions, centered subject,
        plain flat background for easy cutout, no text, no watermark"
```

- 全局色板 12 色锁定（含 10 精灵主色，02 §1），提示词写明 hex。
- 光照两段式（顶部柔光 + 底部单档阴影）；描边与 UI 描边同色，角色嵌进纸感 UI 不违和。
- 精灵形象基调：**天气现象拟灵**（云/雾/雨/风的本体形态）+ 简笔五官与小手；同一精灵跨形态保持「天气本体 + 五官」一致。
- 界面语义图标使用 Moodisle 贴纸资产，避免依赖各平台绘制不一致的 Emoji 字形；普通正文不把 Emoji 当作图标。

## 2. 生成工作流（角色一致性）

```
① 设定图   每精灵 1 张三视图设定图（正/侧/背 + 表情三连）→ 人工定稿为 canon 参考图
② 参考生成 以 canon 为参考图出各形态/朝向/表情
           工具链择一（条款核查后记录台账）：Nano Banana(首选,一致性最好) /
           Midjourney --cref+--sref / 即梦图生图 / SDXL+LoRA(兜底)
③ 朝向     只生成 front / back / left 三向；right = left 水平镜像（脚本）
④ 场景     先出 1 张风格锚点图定调，其余 img2img（强度 0.4–0.6）
⑤ 后处理   tool/asset_pipeline 自动化（§4）
⑥ 质检     §5 checklist；不合格回炉（seed 记录在台账）
```

一致性三板斧：canon 设定图全程参考 + seed/风格锁 + 后处理调色归一（色板最近色量化）。

## 4. 后处理流水线（`tool/asset_pipeline.py`）

1. 使用 `tool/intake_picture.py` 做素材命名映射、透明边裁切与尺寸归一；2. `tool/asset_pipeline.py validate` 检查规格内已存在 PNG 的尺寸和透明通道；3. `mirror` 可从左向立绘生成缺失的右向图（需要 Pillow）；4. `manifest` 生成 PNG 路径、尺寸、字节数与 SHA256；5. `deploy` 复制规格内可校验的素材到 `app/assets/`。生成台账仍需人工维护；当前脚本不做 pHash 比对，也不会自动交叉校验 ledger。

## 5. 质检 Checklist

以下内容是资产逐项视觉验收标准，不表示本次已重新逐张检查全部 PNG。

- [ ] 透明底干净、1px 描边完整
- [ ] 色板落在 12 色内
- [ ] 与 canon 轮廓/配色/五官一致；跨朝向脸部不漂移
- [ ] 同精灵跨形态：天气本体特征保留（雷=云朵炸毛、雾=雾团轮廓…）
- [ ] 缩到 64² 仍可辨认（组件场景）
- [ ] 无文字/水印/多余肢体

## 6. 音频（用户提供 BGM + 项目自制 SFX）

`just_audio` 播放器、静音、生命周期和页面事件已接入 Web/Android 共用代码。10 个 SFX 已用项目脚本生成，3 首用户提供的 BGM 已复制；2026-09-28 `flutter analyze`、Web Release 和 Android Release 构建通过，Web/Android 实听验收仍待人工确认。

- 原始文件与合成 WAV：`assets-src/audio/original/`；运行时副本：`app/assets/audio/`。`app/pubspec.yaml` 声明整个运行时音频目录。
- SFX：`tap.wav`、`add.wav`、`complete.wav`、`capture.wav`、`evolve.wav`、`light.wav`、`loot.wav`、`levelup.wav`、`error.wav`、`glance.wav`。由 `tool/generate_audio_sfx.py` 使用 Python 标准库离线确定性合成，PCM WAV、44.1 kHz、16-bit、mono；tap 为 75 ms，其余 240–960 ms，不含第三方采样。每个声音的固定 seed、参数和 SHA-256 见 `assets-src/audio/manifest.csv`。
- BGM：`Barefoot_on_the_Lawn.mp3`（177.498 秒）暂映射为晴朗，`Through_the_Orchard_Gate.mp3`（182.521 秒）暂映射为薄雾，`Running_Toward_The_Horizon.mp3`（177.629 秒）暂映射为夜晚。原件保留文件名，运行时副本重命名为 `bgm_sunny.mp3`、`bgm_mist.mp3`、`bgm_night.mp3`；三首均为 44.1 kHz stereo MP3，平均码率约 192 kbps，按位复制且未转码。标题映射尚待实听确认。
- `assets-src/audio/manifest.csv` 记录来源、工具/模型、prompt 或“不适用”、seed/参数、生成日期、权利信息与 SHA-256。用户未提供的 BGM 模型、prompt、生成日期及授权条款均记为“未提供”；文件内 C2PA 签名不用于推断模型或授权。
- 音频项目记录见 `assets-src/ledger.md`。已接入运行时资源不代表音质、BGM 映射、循环、静音和各交互触发已完成 Web/Android 实听验收。
