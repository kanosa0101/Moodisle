## 4. 当前演示范围

适合在测试环境演示的主流程：启动应用并完成首次引导；录入一条待办并选择情绪；完成待办后查看伙伴与图鉴；进入心屿、专注和成长页；在满足解锁条件时再测试回廊。

桌面小组件、灵动岛、通知、触感和暗色主题属于设计目标或后续范围；音频资源已打包并接入播放器，Web/Android 实际声音已于 2026-10-01 经用户人工实听验收。**范围决策（2026-10-01）**：上述五项设备能力与 V2 素材接入（30 张表情差分、10 张 canon 设定图、10 张地标）标为后续范围，不列入当前课程交付；分享保持剪贴板形态。上述能力不应放进当前“已完成演示”清单。进入下一轮用户测试前，应逐项完成本节验收，或明确标为后续范围并在 docs/09 保持待办状态。
