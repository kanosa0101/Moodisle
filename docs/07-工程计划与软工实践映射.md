## 4. 当前演示范围

适合在测试环境演示的主流程：启动应用并完成首次引导；录入一条待办并选择情绪；完成待办后查看伙伴与图鉴；进入心屿、专注和成长页；在满足解锁条件时再测试回廊。

桌面小组件、灵动岛、通知、音效、触感和暗色主题属于设计目标或后续范围，不应放进当前“已完成演示”清单。通过用户测试前，先解决或记录本节列出的待复现问题。
