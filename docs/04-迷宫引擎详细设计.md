# 心晴屿 Moodisle · 心绪回廊（迷宫引擎）详细设计

> v1.0。机制思想（完全信息策略迷宫 / 可解性保证的程序化生成）为行业通用设计，本文档为**独立编写的实现规格**：全部参数、公式、不变式与表达为本项目原创（00 文档 R3）。

## 1. 概述

- 玩法：操控出战精灵在多层格子迷宫中「等级吞噬」推进——我方等级 ≥ 怪则必胜并吞并其等级；< 则该格不可入。完全信息，强调「先想后走」。
- 引擎分三部分：**生成器**（§3）、**求解器**（§4，保证可解）、**运行时**（§5）。生成与求解为纯函数（入参含种子 RNG），可无头单测。

**起手战力**：`base = 2 + ⌊看岛人等级/2⌋`，按出战精灵形态加 `{晴态:+1, 虹态:+2, 觉醒态:+3}`。
**Boss 等级**：`max(起手+2, round(起手×1.3 + 本层最高怪×1.1 + 层深×2))`，镇守最终层出口邻格。
**怪等级**：随 BFS 距离场放大：`round(起手 × (0.35+rng×0.45) × min(1.5, 0.4 + dist×0.10) × (1 + 层深×0.22))`；精英 ×1.5。

## 3. 生成管线（`MazeGenerator.generate(zone, zi, startLevel, seed) → Floors[]`）

对每层 `d`：

```
1 底盘: w×h 全 floor；随机布墙（密度 = tuning.wallPct），起点(左列随机行)/出口(右列随机行)为锚点
2 连通兜底: BFS 判定出口可达；不可达则凿 L 形通路
3 锁门: 仅选满足 I1 的格（见不变式）；门后隔出的「口袋」登记，口袋格预留
4 怪: 按怪量系数布怪于空闲格，等级按距离场公式；精英按概率升级
5 神龛: 优先入门口袋（I4），余量落远角（按距离场降序）
6 钥匙: 门数把钥匙全数放在「不穿门可达」区（I3）
7 战力道具: 1–2 个垫脚石（+等级）
8 陷阱: 仅选满足 I2 的格（0 陷阱层跳过）
9 迷雾层道具: zi≥4 时按 2–3 个「提灯」布设（占用普通道具名额）
10 Boss: 最终层在出口邻格放置（I6）
11 校验: solver(startLevel).ok == true，否则重试 ≤40 次；仍失败 → 降级兜底（怪等级 ×0.9 步进降至 ×0.3）
12 层间衔接: 本层求解器终局等级作为下层起手估值
跨层门（tuning>0 且层数≥3）: 早层空闲格 → 跳过 ≥1 层直达目标层入口（放弃中间层奖励）
```

### 3.1 不变式（生成器必须满足，测试逐条断言）

| # | 不变式 |
|---|---|
| I1 | 出口可达性**永不依赖门**：门格仅能放在「把该格视为墙后出口仍可达」的位置 |
| I2 | 陷阱格必满足「把该格视为墙后出口仍可达」（求解器永远绕行，绝不踩） |
| I3 | 钥匙数量 ≥ 门数量，且全部位于「不穿过任何门即可达」区域 |
| I4 | 神龛优先放门后口袋（开门换增益的冒险设计） |
| I5 | 每层产出必须通过求解器校验；降级兜底后仍必须通过 |
| I6 | Boss 存在时邻接出口；无可用邻格则本层无 Boss（出口直达） |
| I7 | 怪等级 ≥ 1；全图无「既不可达又必须吃」的怪（由 I1/I2 + 求解器共同保证） |

## 4. 求解器（`MazeSolver.solvable(floors, startLevel) → {ok, finalLevel}`）

贪心模拟，判定「是否存在通关吃级顺序」：

```
loop (guard 800):
  reach = BFS(start)：门(未开)=墙、陷阱=墙、活怪=阻挡；层内传送阵互通
  if exit ∈ reach → return ok
  ① 收取 reach 内全部非陷阱道具（钥匙计数 / 战力+神龛加级）；有进展 → continue
  ② 有钥匙 → 开一扇与 reach 相邻的门 → continue
  ③ 找「与 reach 相邻(或经传送阵) 且 level ≤ 我方」的最弱怪 → 吞并 → continue
  ④ 无动作 → return 失败
```

**完备性论证**：我方等级与已收集/已吞并集合均单调递增，任何可行解的中间状态都可被「最弱优先」贪心到达（先吃更弱的怪只会让后续更强的怪更早可吃），故贪心失败 ⇒ 无解。复杂度 `O(guard × (V+E) × F)`，9×9×4 层规模下毫秒级。

## 5. 运行时规则

- **交互**：点击格 → 两段式自动寻路（先绕陷阱，不可达再允许踩）；方向键 / 虚拟方向垫单步。路径执行逐格结算：开门扣钥匙、拾取、吞噬（等级不足则整段回退并提示）、跨层门即踏即传送。
- **吞噬**：到达怪格判定 `我方 ≥ 怪`；胜则 `等级 += 怪等级`，本步结束（停留决策）；不足则该路径作废。
- **撤销**：每次「操作」（一段路径）前压快照（位置/等级/钥匙/已吃/已拾/已开），上限 200；撤销置 `usedUndo=true`。
- **重开本层**：清本层作用域状态，等级/钥匙回到进层快照；同样置 `usedUndo=true`。
- **迷雾模式**（zi≥4）：视野半径 2 格（切比雪夫距离），「提灯」+1（上限 5）；高亮可达集合只在视野内渲染。
- **双精灵编队**（解锁：虹晶×5）：出战带 2 只，各 10 步体力，耗尽自动轮换；**主动技**消耗 1 虹晶/次：探路（高亮最近钥匙/门 10s）· 安抚（当层最弱怪 −30% 等级）· 寻宝（高亮 1 个未拾道具 10s）· 破障（无视 1 次等级差强吃，每回廊 1 次）。羁绊 Lv5 技效 +25%，Lv8 每层可用 2 次。
- **完美通关**：全道具收集（陷阱除外，见 I2 语义）+ 全怪击败 + 未撤销未重开。

## 6. 结算公式

```
晨露 = round((1 + ⌊击杀/3⌋) × lootMul)         晴晶 = round((1 + 层数) × lootMul)
精英 → 顺风 ×精英击杀            Boss → 心结碎片 ×1（×3 合成云母）
完美 → 额外 晨露×2 + 心结碎片×1
经验 = 20 + 击杀×4 + (Boss ? 30 : 0)             放晴 += 2 + 层数
迷雾模式通关 → 雾露 +1            暖锋/顺风 buff 各消耗 1 次
时令掉落：当季主题道具 28% 概率 / 节日期间 50%
```
