## 0. 使用方式与全局规范

### 0.1 Prompt 拼装公式

```
完整 prompt = [BASE 风格基座] + [主体描述] + [形态/姿态/场景增量] + [负面词]
```

- **BASE（所有资产共用）**：
  `soft flat sticker illustration, thick rounded warm-brown (#5a3e22) outline, pastel palette, subtle grain texture, kawaii proportions, centered subject, plain flat background for easy cutout, no text, no watermark`
- **负面词（全资产共用）**：
  `text, watermark, signature, human, photorealistic, 3d render, harsh shadows, gore, horror, complex background, gradient banding, jpeg artifacts, extra limbs`
- 中文描述列用于人工理解与国内工具（即梦/豆包）直填；英文片段用于 MJ/SDXL 系工具。两者语义一致，以中文描述为准。

### 0.2 全局视觉规范

| 要素 | 规范 |
|---|---|
| 视角 | 精灵/道具：正面平视或微 3/4；岛屿地图：等距偏俯视（约 30°） |
| 光照 | 两段式：顶部柔光 + 底部单档投影，禁止复杂光效 |
| 描边 | 暖棕 #5a3e22 圆角粗描边，全资产统一 |
| 色板 | 12 色锁定：8 个 UI 色（#e0a23c 橙 / #5fe08e 绿 / #5b8fd6 雨蓝 / #a06fe0 电紫 / #e05f8f 涡粉 / #39c3b0 风青 / #7fd0e8 霜蓝 / #fffaf0 纸白）+ 4 个精灵专属辅助色 |
| 表情 | 五官极简：圆点眼/线眉/小 o 嘴；情绪靠轮廓与姿态表达，不靠五官堆细节 |
| 背景 | 角色与道具一律纯色平底（抠图用）；仅场景类允许环境绘制 |
| UI 图标 | 用本项目贴纸资产表达界面语义，不用系统 Emoji 字形；保证 Web/Android 的图形、描边和颜色一致 |

## 3. 精灵资产矩阵（40 行 ≈ 120 张运行时图）

> 每行 = `assets-src/pets/{emotion}/st{n}_{branch}_{dir}.png`；描述 = §1 canon + §2.1 形态增量 + **§2.3 对应朝向的逐字描述**（§2.3 为正式出图真源，本表各列仅作该形态下的增量备注，与朝向描述叠加使用）。

**命名映射说明（生成名 → 项目名）**：生成器输出的 `st2_sunny` / `st3_rainbow` 由
`tool/intake_picture.py` 统一改名为 `st2_clear` / `st3_clear`（虹态语义并入 clear 段），
`st4_constellation` / `st4_deepcurrent` 与规范一致；`right` 由 left 镜像或生成器直出均可。

**图片接入通道（工程侧已就绪）**：`app/assets/pets/{emotion}/st{n}_{branch}_{dir}.png` 放入即生效——`PetSprite` 组件优先加载正式图，缺失时自动回退到程序化占位（主色 + 天气符号），无需改代码；`tool/asset_pipeline.py` 可校验文件规格并生成 SHA256 manifest，生成台账需人工核对。

**表情/动作变体（帧动画素材，V2）**：每精灵 3 套 idle（常规/开心小跳/性格小动作），命名 `st{n}_{branch}_{dir}_{idle1|2|3}.png`；M2 运行时先由引擎位移/缩放模拟，帧图就位后无缝替换。
