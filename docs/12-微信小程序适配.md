# 心晴屿 Moodisle · 微信小程序适配

> 本文记录 `feat/wechat-miniprogram` 分支的小程序端现状、构建链路、平台边界与验收证据（基线 `0231f87`，2026-10-24）。小程序端与 Web/Android/iOS 共用 `app/` 全部页面、领域逻辑与美术资源，以 Android 端已验收体验（2026-10-01 设备验收）为对齐基准；差异只发生在构建链路与平台能力触点，均在本文明示。

## 1. 范围与定位

- 交付形态：mp-flutter（pub.dev `flutter_miniprogram` 0.3.2，固定版本）把现有 Flutter 应用编译为微信小程序；Flutter Web + CanvasKit 在小程序内运行，宿主 Dart 代码零分叉，仅以 `--dart-define=MOODISLE_MP=1` 构建门控少量平台分支。
- 分支纪律：全部工作在 `feat/wechat-miniprogram` 分支，`main` 与 `ci.yml` 不动；小程序产物不进版本库（`app/build/weapp/`，gitignored）。
- 运行要求：微信基础库 ≥ 3.15.0。

## 2. 构建链路（Windows 开发机不构建）

mp-flutter 构建 CLI 仅支持 macOS/Linux，Windows 未支持；因此全部构建走 GitHub Actions（`wechat-miniprogram-spike.yml`，ubuntu + Flutter 3.41.9 + Node 20 + Brotli），产物经固定 prerelease `weapp-spike-latest` 免认证下载，解压到仓库内规范路径 `app/build/weapp/` 供微信开发者工具导入。

```
push 工作流（或手动 Run workflow，可填真实 appid）
  → 资产瘦身（tool/weapp_asset_diet.py apply/check，构建期原地变换，仓库资产不变）
  → CI 内摘除 build_runner/drift_dev（Dart 3.11 解析约束，见 §3）→ flutter pub get
  → dart run flutter_miniprogram doctor
  → dart run flutter_miniprogram --appid <输入或Secret或touristappid> --dart-define=MOODISLE_MP=1
  → 体积报告（notice 注解外显）+ zip 发布 prerelease
```

构建失败时日志尾部经 workflow annotation 外显（免认证可读）。真机包入口：**Actions → WeChat Mini Program spike → Run workflow**，`appid` 填已注册 AppID（或配置 `WECHAT_APPID` Secret 一劳永逸）；默认退回 `touristappid` 游客模式（仅开发者工具可用）。

## 3. 工具链硬约束（排障结论）

| 约束 | 事实 | 处理 |
|---|---|---|
| Flutter 版本硬门 | mp-flutter 0.3.2 仅验证 Flutter 3.41.x（Dart 3.11.5）；`doctor` 放行更高版本但 `build` 以退出码 3 拒绝（3.47.5 实测） | 工作流固定 3.41.9；`tool/check_platform_consistency.py` 按工作流映射版本（ci/ios 3.47.5，spike 3.41.9） |
| 仓库 lock 不兼容 | 仓库 `pubspec.lock` 由 3.47.5 生成，Dart 下限 3.12，与 3.41.9 无解 | CI 内删除 lock 重新解析（钉死的运行时版本 drift 2.35.2 / drift_flutter 0.3.1 / drift_dev 2.35.1 均兼容 Dart ≥3.10） |
| analyzer/meta 冲突 | `build_runner ^2.16.2 → analyzer ^14.3.0 → meta ^1.18.3` 与 3.41.9 SDK 钉死的 meta 1.17.0 冲突，Dart 3.11 下无解 | CI 内临时从 pubspec 摘除 build_runner/drift_dev（仅本地代码生成用，`database.g.dart` 已入库）；仓库文件不变 |
| 插件垫片 | http/dio/shared_preferences/NetworkImage 有垫片；**just_audio、path_provider、drift/SQLite 无垫片**；localStorage 由 `wx.*StorageSync` 垫片承载（`mpf:` 前缀，单键 1MB / 总量 10MB） | 见 §5 触点决策 |

## 4. 包体与资产瘦身

微信硬限：主包/单包 ≤ 2MB、总包 ≤ 30MB（构建期校验，超限退出码 2）。仓库 `app/assets` 原始约 94MB，必须构建期瘦身（`tool/weapp_asset_diet.py`，仅作用于 CI 临时 checkout）：

- 剔除 `assets/audio/`（13MB，当前无音构建；M7 音频补齐时改为 WAV 转码回包）；
- PNG 降采样（island 1536→1024、postcards 1200→768、ui 1024→768，其余 ≤512 原尺寸）+ 256 色量化（Floyd-Steinberg 抖动、保留透明）。

实测：PNG 79.0MB → **11.2MB**（pets 43.1→7.4、island 16.9→1.1）；weapp 产物 zip **20MB** / 解压 31MB（主包 + pkg-dart×2 + pkg-wasm 1.8M + pkg-cjk/cjkb 各 1.2M + pkg-assets×34 + pkg-fonts×7 + pkg-notices 1.8M）。体积门禁 `check`（图片 ≤20MB）已入工作流；脚本带 7 条 Python 单测。若后续需要余量：licenses 分包可 `--no-licenses` 省 1.8MB，island 量化档位可回调（用户 2026-10-24 模拟器走查未见画质问题）。

## 5. 平台触点与适配决策

| 触点 | 小程序现状 | 决策与证据 |
|---|---|---|
| SQLite/Drift | wasm/worker 不可用 | `MOODISLE_MP` 门控下 `main.dart` 不注入 `SqliteGameRepository`，原生走 JSON SaveStore（不触发数据库失败弹窗）；模拟器启动正常（2026-10-24） |
| JSON 存档落地 | localStorage 垫片 → wx 存储 | 走 `save_store_web.dart` 现有路径，mp-flutter 官方垫片承载；满状态存档实测 58KB（300+ 待办），单键 1MB 限内无需分片（单测入档） |
| 音频 | just_audio 无垫片 | 当前无音构建：音频资源不入包，`hasAudio=false` 自动降级（按钮置灰 + "音频素材待接入"）；启动与播放链路静默降级未炸启动（模拟器证实）。**M7 补齐**：`JustAudioPlatform` 的 wx 实现（`wx.createInnerAudioContext` 经 dart:js_interop 桥接）+ WAV 转码回包 |
| 锁屏/生命周期信号 | 无 MethodChannel | `MissingPluginException`/`PlatformException` 均已捕获（与 web 同路径）；靠 AppLifecycleState（onHide/onShow 映射 hidden/resumed）驱动专注暂停 |
| 专注语义 | 切后台即暂停、无锁屏信号 | 与 web 同边界；专注页文案按平台三分支如实表述（`kMoodisleMp`） |
| 剪贴板 | Clipboard 可能抛错/空 | `copyTextWithFallback` / `pasteTextWithFallback` 降级：长按复制弹窗 / 手动粘贴框（`shared/widgets/clipboard_fallback.dart`） |
| 字体 | MoodisleSans 子集 916KB 随包 | 走工具自动分包（pkg-fonts-*）；A/B 实验 B 案（剔除内置字体用 pkg-cjk）未采纳——保留与安卓端一致的排版 |
| 触感/通知/小组件 | 不适用/未接 | 与三端"后续范围"口径一致 |

## 7. 与安卓端（对齐基准）的已知差异

1. 无音频（M7 补齐前）：音效按钮置灰属预期。
2. 锁屏继续计时不可得：小程序语义 = 切后台暂停（同 web），文案已如实区分。
3. 剪贴板视环境走长按复制/手动粘贴降级；导出内容与格式不变。
4. 资产为构建期有损压缩版（量化+限宽）；模拟器走查未见可感画质问题，档位可回调。
5. 冷启动含 CanvasKit 与分包按需加载，首次进入资源页可能略慢于安卓端。
