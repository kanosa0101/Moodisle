## 1. 一句话定位

**心晴屿：一座会反映你心情天气的小岛。** 把真实待办化作情绪天气精灵收服陪伴，用「无愧疚」的陪伴式专注，和它一起等一场放晴。

Slogan：**心情，是可以放晴的。**（副：雾会散，它陪你等。）

## 2. 竞品格局与错位竞争

| 类型 | 代表 | 核心机制 | 短板（我们的切入点） |
|---|---|---|---|
| 惩罚型 | Forest、番茄ToDo、潮汐 | 番茄钟中离开 App → 树枯死 | 负罪感驱动，对焦虑人群是二次伤害 |
| 无惩罚养成型 | Flora、Focus Friend | 组队互督 / 织毛衣豆子 + 装饰奖励 | 伙伴是通用形象，与「你为什么拖延」无关；无任务锚点 |
| 宠物陪伴型 | Finch、Focus Dog | 自我关怀目标养小鸟 / 专注兑换公益 | 缺少可玩策略层，任务感弱 |
| 岛屿养成型 | Focus Island、小岛番茄时间 | 专注让荒岛长出树木，昼夜氛围 | 岛只是进度条的皮肤，无情绪维度 |
| 社交陪伴型 | Focus Traveller | 好友组队登山，美术完成度高 | 强联机依赖服务器与账号，社交压力 |

### 2.1 五个差异化主张

1. **情绪锚定的天气精灵**（vs Focus Friend）
   伙伴不是通用形象，而是**从你自己的待办情绪里诞生的天气精灵**：录入「我不想写周报（拖延）」，雾灵便在岛上现身。收服它 = 承认并安放这种情绪。10 种情绪 = 10 种天气现象，是我们独立设计的世界观 IP。

2. **羁绊式陪伴专注**（vs Forest 死亡惩罚）
   专注时精灵上岛陪你；中途离开它只会**原地张望等你**（2 分钟宽限），超时本次作废但零惩罚。完成涨**羁绊**——双向陪伴的记录，不是防作弊数值。愧疚感被替换成「它还在等你」。

3. **情绪气候系统**（vs Focus Island 昼夜）
   岛的天气是你**近 7 天情绪结构的可视化**：待办积压且焦虑类占比高 → 岛起「心雾」；疏导达成 → 雾散虹光；连晴 → 极光。且**雾不是坏事**：雾中可拾「雾露」——低谷期上岛必有正反馈，颠覆「负面 = 惩罚」的行业惯例。

4. **无服务器异步社交**（vs Focus Traveller）
   岛屿明信片 / 漂流瓶：生成导入码，好友导入后你的招牌精灵到他岛上**客住 72 小时**。零账号、零服务器、零社交压力。

5. **任务流 + 专注流双驱动**
   全行业是时间流；我们双流各自成立：**任务驱动收服与生态，专注驱动羁绊与星屑经济**，互不绑架。

### 2.2 设计红线

- **零惩罚**：断签、断链、专注中断、回廊失败——只影响当次收益，不扣已有资产。
- **只卖外观**：付费/奖励不触碰数值与进度。
- **隐私优先**：无账号；社交靠导入码；情绪数据仅存本地。
- **反成瘾**：久坐提醒、休息演出，不做时长焦虑。
- **表达原创**（清洁室）：见 00 文档，R1~R3 铁律。

## 3. 目标用户与核心场景

- **主用户**：18–30 岁学生 / 职场新人，有拖延与焦虑困扰，被 Forest 类工具劝退过。
- 场景 A（课间）：列 3 件待办 → 3 只精灵在雾中现身 → 完成一件 → 收服 + 心雾散开一角。
- 场景 B（自习）：带雾灵开 25min 陪伴专注 → 它在你旁边慢慢飘 → 完成涨羁绊。
- 场景 C（周末）：心晴周报显示本周雷雨天（焦虑）占比下降、共鸣链 ×4 → 生成明信片发给朋友。
- 场景 D（低谷）：什么都不想做 → 岛上起雾，但雾里有雾露可捡 → 「今天捡了 3 滴雾露」也算照顾了自己。

## 4. 核心循环

```
【安置环 · 每日】                     【陪伴环 · 每次专注】
录入待办(登记情绪) → 精灵现身(阴态)    选精灵开专注 → 陪伴视图
      │完成                             │中断→张望(宽限2min,零罚)
      ▼                                 ▼
收服(晴态) + 天气共鸣共演 + 放晴度↑    羁绊↑ + 星屑↑ → 解锁同行/挂件
      │                                 │
      └───────────┬─────────────────────┘
                  ▼
【探索环 · 每周】行动力 → 心绪回廊(迷宫) → 晨露/晴晶 → 培育进化 → 虹态/觉醒态
                  │
Meta：情绪气候(实时) · 心晴周报(每周) · 群岛明信片(异步) · 四季(按月)
```

三环各自独立可玩、互相增益；任何一环停下，其余照常运转且无损失。

## 5. 机制参考与原创表达对照（版权卫生核心表）

玩法思想属行业通用设计（同类竞品亦采用）；下表声明：左列**思想**允许参考，右列全部为我们的原创表达。

| 机制思想（可参考） | 我们的原创表达 |
|---|---|
| 真实待办 → 化作生物，完成即收服 | 天气精灵世界观；情绪=天气现象；阴态→晴态的「放晴」演出 |
| 按固定顺序连续完成获得连击奖励 | **天气循环环**（雷→雨→雾→霭→云→涡→风→霜→星→霞→雷），环序与情绪学解释自研（02 §4） |
| 同类坚持次数驱动两段进化 | 晴态/虹态/觉醒态三段；星宿线/深流线分支与星图呈现 |
| 「了解玩家才能解开」的多层迷宫 | 心绪回廊：天气主题十区、心结巨灵、迷雾模式、双精灵编队（数值全自研） |
| 离线时长结算的派遣玩法 | 精灵「云游」：三条天气航线（季风/信风/极地），纪念品为天气收藏 |
| 完成真实任务获得行动力 | 行动力 + 心晴指数体系；放晴度进度 |
| 签到/每日任务回流 | 连晴天数（零惩罚转阴）+ 今日心晴问候 |
| 零惩罚哲学、外观付费、PWA 离线 | 一致采纳为设计原则（思想层面），实现全自研 |

**不参考**原型的部分：美术、音频、全部专有名词、数值表（我们的数值在 02/03/04 文档独立设计）、存档格式、代码结构。

## 6. 多端差异体验

| 能力 | Android | iOS | Web（PWA 轻量版） |

## 7. 命名与 IP

- 产品名 **心晴屿 Moodisle**（查重与备选见 00 文档 §6）。
- 命名系统延伸：每日问候「今日心晴」、天气角标「心晴指数」、周报「心晴周报」、连击「连晴」。
- 图标意象：圆角小岛上空，一朵雾化成笑脸的云。
- 精灵命名保留中英双名体系（如 雷灵 Zappy），全部为自研（见 02 §1）。
