## 0. 术语总原则

- **零惩罚**：失败/中断只影响当次收益，不扣减已有资产。
- **双货币**：晴晶（任务/回廊产出，通用）与 星屑（专注独占，买陪伴向外观）。
- **事件流架构**：规则计算全部在逻辑内核完成，以事件抛给 UI 演出（03 文档 §7）。

| 小憩 | 15 min | ×1 |

| 深潜 | 50 min（每 25min 轻提醒） | ×1.5 |
| 自定义 | 5–120 min | ×1 |

### 2.2 运行规则（零惩罚核心）

- 开始：选 1 只已收服精灵为「陪伴位」。
- 专注视图：心岛局部特写，精灵做性格化小动作（每只 3 套 idle）。
- **中断**：离开 App 计时暂停，精灵「张望」；2 分钟内回 → 无缝继续；超时 → 本次作废，精灵打哈欠「那你先忙～」。`今日张望次数` 仅进周报自察，不影响任何数值。
- **完成**：羁绊 +分钟数；星屑 = `⌊分钟/5 × 档位系数 × (1+羁绊等级×0.05)⌋`；庆祝演出。

## 3. 情绪气候系统（S3 · 核心差异化）

### 3.1 心雾浓度（滚动 7 天窗口）

```
stress = Σ 未完成待办: difficulty × 情绪权重(anxious/neikao 1.3, emo/burnout 1.1, 其余 1.0)
relief = 2×近7天完成待办数 + 近7天专注分钟/15
fog%   = clamp((stress − relief) / (stress + relief + 4), 0, 1) × 100
```

### 3.2 气候类型

| 气候 | 条件 | 视觉 | 玩法 |
|---|---|---|---|
| ☀️ 晴 | fog < 30 | 明亮 | 基准 |
| 🌫️ 薄雾 | 30–59 | 岛缘薄雾 | 雾露 ×2/日 |
| 🌁 浓雾 | ≥ 60 | 半屏雾层 | 雾露 ×4/日；完成待办额外 +1 放晴 |
| 🌈 虹光 | 24h 内共鸣链 ×3 | 彩虹共演 | BGM 换虹光曲 30min |
| 🌌 极光 | 连晴 ≥ 7 天 | 极光带 | 展示层 |
| ☄️ 星雨 | 周专注 ≥ 150min | 夜空流星 | 展示层 |
| 🌙 暮雪 | 连续 3 天零完成 | 雪落围炉 | 雾露照常（低谷也有收获） |

防抖动：气候档位切换需「新档位连续 2 次日重算成立」或单日跳变 >25，避免闪烁（03 §6）。

### 3.3 雾露（负面期资源）

每日按档投放 0/2/4（暮雪 +1，上限 5）；使用「拥抱心情」：放晴 +5% + 随机（经验+15 / 晨露×1 / 晴晶×3）。设计意图：把「情绪不好」从需要隐藏的状态变成可收集的风景。

## 4. 天气共鸣（S4 · 连携系统）

### 4.1 天气循环环（自研环序 + 情绪学解释）

```
雷 → 雨 → 雾 → 霭 → 云 → 涡 → 风 → 霜 → 星 → 霞 → 雷 …
(焦虑)(低落)(拖延)(倦怠)(内耗)(混乱)(分心)(完美主义)(错失)(社恐)(回到焦虑)
```

环序依据「情绪的自然滑动」：雷雨过后情绪落下来（雷→雨）；雨后起雾提不起劲（雨→雾）；雾积成霾越拖越蔫（雾→霭）；蔫着蔫着开始在头顶盘旋想太多（霭→云）；盘旋成结生活变乱（云→涡）；乱流四起注意力吹散（涡→风）；风停了反而僵在「要做得完美」（风→霜）；僵到怕错过一切（霜→星）；观望久了不敢加入（星→霞）；霞光退场天边又聚起新的雷（霞→雷）。

### 4.2 规则

- 完成情绪 A 后 **24h 内**完成 A 的循环后继 B → 触发「共演时刻」：A、B 两精灵在所属微气候区共演疏导动画（3.5s + 属性色粒子），掉落 1 枚**虹晶**。
- 共鸣链 ×N 横幅与历史最长保留；链 3 额外送虹晶 ×1，链 5 送暖锋 ×1；断链零惩罚。
- 每环奖励：经验 +10/环、放晴 +1%/环（自第 2 环起）。
- **虹晶用途**：双精灵编队解锁（5 枚）、回廊主动技充能（1 枚/次）、培育加速（1 枚 = 晨露 +1）。

## 5. 图鉴与培育（S5）

- 形态：**阴态**（未收服，引擎灰化滤镜呈现，不单独出图）→ **晴态**（<5）→ **虹态**（5–9）→ **觉醒态**（≥10）。
- 进化进度可喂「晨露」+1（回廊主产）；觉醒态培育圆满（10/10）。
- 觉醒分支判定（觉醒那一刻快照）：
  - `风雨值` = anxious + chaos 累计完成数（与雷雨缠斗的量）
  - `晴耕值` = 连晴天数 + 历史最长共鸣链（稳定坚持的量）
  - 风雨值 > 晴耕值 → **深流线**（与雷雨长久缠斗，化作深流异兽）；否则 → **星宿线**（日复一日的坚持，凝作星宿灵兽）
- 成长页「习惯星图」雷达图实时可视化两值，让分支**提前可见**。

## 6. 心绪回廊（S6 · 迷宫探索，详细设计见 04 文档）

- **继承的思想**：完全信息策略迷宫、等级吞噬、可解性保证的程序化生成、撤销/重开零惩罚。
- **十回廊**（按累计探索次数解锁）：雷鸣丘(0) → 雨檐巷(3) → 雾径(6) → 霭原(10) → 云顶回廊(15) → 涡眼遗迹(21) → 风哨崖(28) → 霜晶洞(36) → 星陨原(45) → 霞光阶(55)。每区 Boss = 该天气的**心结巨灵**。
- **新机制**：①迷雾模式（区域 5 起视野半径 2，拾「提灯」+1，上限 5）②双精灵编队（虹晶 5 解锁，体力轮换 + 4 种主动技：探路/安抚/寻宝/破障，1 虹晶/次）③回廊罗盘（每日种子迷宫 + 成绩码异步比拼）。
- 门槛：区域解锁 + 行动力 1 + 每日次数（基础 5 + 看岛人加成）。

## 9. 每日与每周回流（S9）

- **连晴天数**：完成待办当天为「晴天」；连续则 +1，中断「转阴」——只重置计数，不清成就（零惩罚）。
- **今日心晴**：每日首次进入问候（时段文案 + 雾情速报：「今天岛上有点雾，捡 2 滴雾露就好」）。
- **7 日循环签到**：断签重置不清零；第 7 天大奖云母。
- **每日任务**：完成 3 待办 / 专注 1 次 / 共鸣链 ×3（加法/取峰两种计法）。
- **心晴周报（周日 20:00 可生成）**：情绪构成环图、完成/专注热力、共鸣链走势、气候曲线；规则模板引擎（≥30 条文案按数据分支）生成一句温柔洞察；一键分享图喂给明信片社交。纯本地无 LLM（V2 可选接）。

## 10. 群岛社交（S10 · 零服务器异步）

- **岛屿明信片**：一键生成岛卡片（岛景 + 3 项数据 + 导入码）。好友导入 → 明信片挂上信标 + 对方**招牌精灵**（羁绊最高者）到你岛客住 72h（外观 NPC，每日换位置）。
- **漂流瓶**：≤50 字塞瓶 → 瓶码；拾取者读到文字 + 岛名，可回赠 1 晴晶。
- 码格式：`MDSL·BASE32(版本|设备ID|签名|载荷)`，本地签名，无后端；换机 = 导出全档码。

## 12. 成就（MVP 12 条示例）

初次放晴（首次收服）/ 连晴 3·7 天 / 图鉴集齐 / 首次虹态·觉醒态 / 心雾散尽（放晴 100%）/ 首次共演 / 共鸣链 ×3·×5 / 星宿同游·深流同游（两分支）/ 雾中拾荒（累计 20 雾露）/ 笔友（首次明信片互通）/ 深潜者（10 次深潜）/ 心流同频（任一精灵羁绊 Lv10）。
